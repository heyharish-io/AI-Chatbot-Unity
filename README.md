# AI Chatbot - Unity

A standalone AI chatbot built in Unity using the Gemini API.

## Overview

This project demonstrates a conversational AI interface developed in Unity. Users can enter questions through the in-game chat interface and receive AI-generated responses directly inside the application.

## Features

- AI-powered question and answer system
- Gemini API integration
- Interactive Unity chatbot UI
- Text input field for user questions
- AI response display
- Scrollable response area
- "Thinking..." response state
- Error handling for API and network failures
- Android-ready Unity project

## Technologies

- Unity
- C#
- Gemini API
- UnityWebRequest
- TextMeshPro
- Unity UI

## How It Works

User enters a question  
↓  
Ask AI button  
↓  
Unity C# Script  
↓  
Gemini API  
↓  
AI-generated response  
↓  
Unity Chat UI

## Setup

1. Open the project using the compatible Unity version.
2. Open the chatbot scene.
3. Configure the required Gemini API access.
4. Assign the required UI references in the `GeminiAI` component.
5. Run the project.
6. Enter a question and press **ASK AI**.

## Security Note

API keys should not be hard-coded into a public Unity project or committed to Git.

For production deployment, API requests should be routed through a secure backend or another appropriate secret-management solution.
